# ChatGPT / Codex app submission

Generated by following OpenAI's `$chatgpt-app-submission` skill against this MCP server.

## Upload file

[`chatgpt-app-submission.json`](../chatgpt-app-submission.json) — upload this in the OpenAI plugin submission portal to prefill App Info, MCP tool hints, and test cases.

## MCP endpoint for the form

- **URL (Universal):** `https://mcp.anomalia.so/mcp`
- **Auth:** OAuth Bearer (same JWT as `anomalia login`)
- **Skills path (plugin):** `plugins/anomalia`
- **Privacy / Terms:** `https://www.anomalia.so/privacy` · `https://www.anomalia.so/terms`

## Before submit checklist

1. Deploy MCP with the latest tool annotations (all three hints set on every tool).
2. In the portal: Scan Tools against `https://mcp.anomalia.so/mcp`.
3. Upload/import the skill from `plugins/anomalia/skills/` (or MCP static skills if exposed).
4. Review the generated JSON — especially open-world publish tools (`approve_posts`, `publish_post`, `publish_article`, `ads_action`, `chat`).
5. Provide reviewer demo credentials that work without MFA if auth is required.
